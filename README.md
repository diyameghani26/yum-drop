# YumDrop 🍕

A food delivery web app built with React.

🔗 Live Demo: https://yum-drop.netlify.app/

## Features

- 🏠 Home page with restaurant listings & categories
- 🛒 Cart with quantity control & bill breakdown
- ❤️ Favourites with localStorage persistence
- 🔐 Auth with session persistence (no re-login on refresh)
- 👤 Profile dashboard with Orders, Addresses & Settings
- 🆘 Help & Support page
- 📱 Fully responsive UI

## Tech Stack

- React
- React Router
- Context API
- localStorage
- Tailwind CSS
